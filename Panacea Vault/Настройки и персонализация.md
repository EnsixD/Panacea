# Настройки и персонализация

`Super + I` открывает настройки оболочки. Поля и переключатели сохраняются в `~/.config/panacea/settings.json`; изменения многих параметров применяются сразу. Наличие конкретного пункта зависит от версии проекта.

| Раздел | Что настраивается |
|---|---|
| Bar & Island | Положение и геометрия острова, предварительный просмотр |
| Media | Поведение медиаплеера |
| Clock & Date | Часы, дата и формат времени |
| Appearance | Палитра, шрифты, язык, настольные виджеты |
| Motion | Анимации и переходы |
| Launcher | Поиск и запуск приложений |
| Notifications | Уведомления, предварительный просмотр, тайминги |
| Control Center | Состав и порядок плиток |
| Lock Screen | Экран блокировки |
| Display | Разрешение, частота, масштаб, ориентация и мониторы |
| Input | Клавиатура, мышь и параметры ввода |
| System | Сведения о системе и обновления |

## Клавиши

`Super + /` показывает редактор сочетаний. Настройки сохраняются в `settings.json`; для Hyprland генерируются файлы конфигурации. В Niri часть параметров может потребовать ручной настройки сохранённого `config.kdl`.

## Цвета и обои

Палитра распространяется на компоненты оболочки и поддерживаемые конфигурации приложений через скрипты проекта. Обои выбираются через `Super + Shift + T`; поддерживаются изображения и видеообои при наличии необходимых программ.

## Язык

Встроенные переводы включают русский, английский и турецкий. Для других системных локалей интерфейс по умолчанию использует английский. Переводы находятся в `panacea/Translations.qml`.
