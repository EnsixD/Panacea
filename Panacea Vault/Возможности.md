# Возможности оболочки

| Страница | Открытие по умолчанию | Возможности |
|---|---|---|
| Быстрые настройки | Super+Z | Wi-Fi, Bluetooth, звук, плеер, запись, батарея, пароли, трей |
| Сети / Bluetooth | Super+Shift+W / B | Поиск сетей и устройств, подключение и сопряжение |
| Уведомления | Super+Shift+N | Карточки, переход в приложение, история, «не беспокоить» |
| Обои | Super+Shift+T | Карусель, предпросмотр статических и видеообоев |
| Рабочие столы | Super+Tab | Сетка и предпросмотр рабочих пространств |
| Поиск | Super+A | Приложения, вычисления, агенты, другие установленные ОС |
| Launchpad | Super+G | Сетка приложений, папки и контекстные действия |
| Буфер | Super+V | История, закрепление, цвета, ссылки, файлы и изображения |
| Файлы | Super+E | Диски, закладки, сортировка, корзина и перетаскивание |
| Медиа | Открытие файла | Просмотр, обрезка изображения и видео, OCR |
| Запись | Super+P | Частота кадров, каталог, звук системы и микрофон |
| Пароли | Super+Shift+P | Зашифрованное хранилище и импорт из браузеров |
| Блокировка | Super+L | Экран блокировки; в Niri также Mod+Alt+L |
| Питание | Ctrl+Alt+Del | Сон, блокировка, выход, перезагрузка и выключение |
| Настройки | Super+I | Оформление, экран, устройства, функции и система |
| Сочетания | Super+/ | Просмотр и переназначение клавиш |

При наведении капсула открывает медиаплеер или быстрые настройки. Escape и щелчок вне окна закрывают страницу. В свёрнутом состоянии отображаются дата, время, рабочий стол, раскладка и батарея.

## Настройки и виджеты

Настройки включают остров, медиа, дату и время, оформление, движение, поиск приложений, уведомления, центр управления, блокировку, экраны, устройства и систему. Виджеты рабочего стола включают часы, сведения о системе и погоде, прогресс дня или года. Текущие сочетания пользователь может изменить в интерфейсе.

## Другие компоненты

Темы GRUB и SDDM оформлены в стиле оболочки. Поиск умеет предлагать одноразовую загрузку другой найденной ОС; операция требует системных прав. Fish, foot, fastfetch и конфигурации компоновщиков поставляются вместе с оболочкой.
