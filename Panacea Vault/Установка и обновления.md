# Установка и обновления

Установка выполняется `install.sh`; кнопка обновления находится в настройках системы и использует `panacea/scripts/update.sh`. Обновляющий скрипт получает исходники и запускает установщик с параметрами обновления.

## Сохранность изменений

`settings.json` объединяется с новыми значениями по умолчанию; сохраняются пользовательские каталоги, обои, история Wi-Fi и закрепления буфера. Предпочтительное место ручных расширений — `~/.config/hypr/custom/`, `~/.config/niri/custom/`, `~/.config/panacea/custom/`, `foot/custom.ini` и `fish/custom.fish`.

`manifest.sh` хранит SHA-256 установленных файлов и при следующем обновлении сохраняет изменённые и добавленные пользователем файлы. При конфликте обновлённая версия сохраняется рядом с суффиксом `.panacea-new`. На первой установке без манифеста сопоставить старые локальные правки с исходной версией невозможно; также существуют резервные копии обновления. Сохраняйте важные данные отдельно.

Зависимости перечислены в установщике; для OCR в Arch необходимы `tesseract`, `tesseract-data-eng` и `tesseract-data-rus`. Доступность пакетов в других дистрибутивах отличается.

## Этапы обновления

1. `update.sh` получает исходники и при необходимости запускает свежую версию самого обновляющего скрипта.
2. Пользовательские файлы и каталоги временно сохраняются; манифест отдельно определяет прямые правки по контрольным суммам.
3. Установщик вызывается с `--no-deps`, `--no-restart` и другими параметрами обновления. На этом этапе пакеты автоматически не устанавливаются.
4. Личное состояние возвращается, прямые правки восстанавливаются, сведения об установленной версии записываются, затем перезапускается оболочка.
5. Отсутствующие зависимости определяются отдельно и могут быть показаны пользователю.

> [!warning] Локальная установленная копия
> Репозиторий и `~/.config/panacea/` — разные каталоги. Коммит в репозитории сам по себе не обновляет запущенную оболочку. При сравнении или ручном переносе файлов сначала учитывайте пользовательские правки установленной копии.

## Полезные параметры установщика

| Параметр | Назначение |
|---|---|
| `--no-deps` | Не устанавливать зависимости |
| `--no-sddm` / `--no-grub` | Не менять тему входа / загрузчика |
| `--no-services` | Пропустить настройку служб |
| `--no-wallpapers` | Пропустить установку набора обоев |
| `--no-restart` | Не перезапускать оболочку |
| `--yes` | Использовать неинтерактивное подтверждение поддерживаемых шагов |

Список и поведение параметров нужно сверять с текущим `install.sh`, прежде чем запускать установщик на важной системе.
