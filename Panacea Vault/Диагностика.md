# Диагностика

> [!tip] Начните с фактической ошибки
> Перед изменением системных файлов проверьте настройки, доступность зависимостей и журнал Quickshell. Держите резервные копии личных данных.

## Оболочка не загрузила изменения

```bash
qs list --all
qs log -c "$HOME/.config/panacea" --no-color -t 100
```

Quickshell может продолжить показывать предыдущую работающую конфигурацию, если новая не загрузилась. Ищите последние `Failed to load configuration`, путь к QML-файлу и номер строки.

## Виджеты не видны или не принимают ввод

Проверьте общий переключатель в **Оформление → Настольные виджеты** и отдельные настройки карточек. Виджеты находятся под обычными окнами: откройте пустой рабочий стол. Для ScratchPad щёлкните внутри поля, а для возврата к приложению — по его окну. Файл заметок находится вне Obsidian, в `~/.local/share/panacea/`.

## OCR не работает

```bash
command -v tesseract
tesseract --list-langs
```

Для русского и английского нужны данные `rus` и `eng`. На Arch это пакеты `tesseract-data-rus` и `tesseract-data-eng`. Если распознавание неточно, попробуйте выбрать только нужную область, увеличить исходное изображение или улучшить контраст.

## Питание не переключается

```bash
busctl --system get-property net.hadess.PowerProfiles /net/hadess/PowerProfiles net.hadess.PowerProfiles ActiveProfile
systemctl status tlp-pd power-profiles-daemon
```

Проверьте доступность службы и поддерживаемые оборудованием профили. Команда `status` может сообщить об отсутствии одной из служб: одновременно нужны не обе, а поставщик соответствующего D-Bus API.

## Обновление и личные изменения

Обновление старается сохранить настройки и прямые правки через манифест. При конфликте проверьте соседний файл с суффиксом `.panacea-new` и содержимое резервной копии. Подробности — [[Установка и обновления]].
