# Пользовательские настройки Niri в Panacea

Этот каталог (`~/.config/niri/custom`) предназначен для ваших собственных настроек композитора Niri.

## Сохранение при обновлениях
При обновлении оболочки Panacea содержимое этого каталога сохраняется автоматически. Ваши изменения в `custom.kdl` **никогда не будут перезаписаны**.

## Как добавить свои настройки
Откройте `custom.kdl` и впишите необходимые директивы KDL (например, свои сочетания клавиш в блоке `binds { ... }`, параметры мониторов `output "..." { ... }` или правила окон `window-rule { ... }`).
