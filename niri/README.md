# Niri + Panacea

Эта папка содержит полную конфигурацию скроллируемого Wayland-композитора **Niri**, адаптированную для работы с оболочкой **Panacea**.

## Структура
- `config.kdl` — основной конфигурационный файл Niri (KDL-формат):
  - Привязки всех горячих клавиш Panacea (`Super+A`, `Super+Z`, `Super+V`, `Super+E`, `Super+P`, `Super+I`, `Super+Tab`, `Super+/` и т.д.);
  - Русская и английская раскладки с переключением по `Alt+Shift`;
  - Плавный скролл колонок, отступы (gaps), скругление углов окон (14px), цветные рамки фокуса;
  - Правила для всплывающих окон (polkit, file chooser, picture-in-picture и др.);
  - Автозапуск Quickshell, терминала foot, клипборда cliphist и сервисов.
- `custom/` — каталог для ваших личных настроек, которые не затираются при обновлениях Panacea (`custom.kdl`).
- `scripts/` — вспомогательные скрипты (установка обоев `wallpaper.sh`, запуск сеанса `start.sh`).

## Автоопределение композитора
Оболочка Panacea автоматически распознает, запущен ли сеанс под Hyprland или под Niri:
- Под **Hyprland** оболочка использует нативный C++ модуль Quickshell Hyprland;
- Под **Niri** оболочка переключается на IPC-протокол Niri (`niri msg` и `event-stream`), синхронизируя рабочие столы, индикатор раскладки, фокус окон и запуск приложений.
